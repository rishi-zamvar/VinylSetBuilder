Vinyl Set Builder

Photograph vinyl labels. Resolve the metadata. Auto-sequence a mixable DJ set.

Point an iPhone at a record label. On-device Vision OCR reads the track listing, the tracks are resolved against music metadata services, and a BPM-gated, harmonically-aware sequencer orders the crate into a set you can actually play.

How it works

  1. Capture — shoot each vinyl label, one side at a time
  2. OCR — Apple Vision reads the label text with bounding boxes
  3. Segment — deterministic geometric clustering splits the label into individual tracks
  4. Resolve — each track is matched to artist, title, BPM and musical key
  5. Sequence — a beam search finds the longest playable run under a BPM tolerance gate, minimising Camelot-wheel distance between neighbours

Data sources

BPM and musical key data is provided by GetSongBPM. Tempo and key information powering the set sequencer comes from https://getsongbpm.com.

Release, artist, label and pressing metadata from Discogs.

Open music encyclopedia data from MusicBrainz, used as a resolution fallback.
