**The distinction that must not be collapsed.** A protocol with no conformance is not
automatically dead. `MetadataResolving`, `LabelSegmenting`, `PhotoCapturing`, `Sequencing` are
**declared seams** — SETUP-02 exists to create them, and the roadmap names the phase that
implements each. The keep/delete rule is therefore:

> Keep a protocol iff a named future phase's requirements implement it. Delete a *conformance*
> that nothing reaches. Deleting a seam because it currently has no caller is deleting the
> architecture.

**The self-match hazard in a TODO gate.** `Scripts/hygiene.sh` will live in `Scripts/`, and
`Scripts/` is inside the swept tree. A gate whose own pattern string contains the literal token
it searches for matches itself and is permanently red — and the usual fix, `--exclude` its own
filename, makes the gate structurally unable to see a real marker in itself. Build the pattern
from concatenated fragments instead (`PAT="$(printf 'TO''DO|FIX''ME')"`), so the script never
contains the literal token and needs no exclusion. Say so in a comment.
