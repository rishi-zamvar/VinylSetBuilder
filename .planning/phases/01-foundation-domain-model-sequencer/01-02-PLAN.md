## AMENDED 2026-08-29 — toolchain reality, VERIFIED BY EXPERIMENT

Do not improvise the build command. The following was determined by actually running each
variant against a throwaway XcodeGen project on this machine.

### Environment facts (verified)

```
xcrun simctl list runtimes     -> EMPTY. Zero simulator runtimes installed.
xcodebuild -showsdks           -> iphoneos26.0, macosx26.0
xcodegen                       -> /opt/homebrew/bin/xcodegen  (installed)
code signing identity in repo  -> none, by design (public repo)
```

Xcode also reports: *"iOS 26.0 is not installed. Please download and install the platform
from Xcode > Settings > Components."* — the iOS **platform support files** are not fully
installed, only the SDK.

### What FAILS (do not use)

| Command | Failure |
|---|---|
| `-scheme X -sdk iphoneos26.0` | `error: Found no destinations for the scheme` |
| `-scheme X -destination 'generic/platform=iOS'` | `Unable to find a destination matching…  iOS 26.0 is not installed` |
| any simulator destination | no runtimes exist |

**Root cause:** *scheme*-based builds resolve a destination, and destination resolution
requires an installed platform. *Target*-based builds skip destination resolution entirely.

### What WORKS — `Scripts/build-app.sh`

```bash
#!/usr/bin/env bash
# Verified 2026-08-29: BUILD SUCCEEDED with no simulator runtime, no platform
# download, and no signing identity. Target-based, NOT scheme-based — see above.
set -euo pipefail
cd "$(dirname "$0")/.."
xcodegen generate --quiet
xcodebuild -project VinylSetBuilder.xcodeproj \
           -target VinylSetBuilder \
           -sdk iphoneos \
           -configuration Debug \
           CODE_SIGNING_ALLOWED=NO \
           CODE_SIGNING_REQUIRED=NO \
           CODE_SIGN_IDENTITY="" \
           build
```

Note `-sdk iphoneos` unpinned, so it keeps working when the SDK version changes.

### If it still fails — never stop and ask

1. `xcodebuild -showsdks` and substitute whatever `iphoneos*` is listed.
2. Drop to `xcodebuild -project … -target … -sdk iphoneos build` with no extra flags.
3. Last resort: reduce the gate to `swift build --package-path VinylSetBuilderCore`,
   record the app-target compile as UNMET in the phase SUMMARY, append it to
   `.planning/UAT-PENDING.md`, and CONTINUE. The run must not stall.

**Never** run `xcodebuild -downloadPlatform iOS` — multi-gigabyte, may prompt for
credentials, and buys nothing (the camera does not work in a simulator anyway).
