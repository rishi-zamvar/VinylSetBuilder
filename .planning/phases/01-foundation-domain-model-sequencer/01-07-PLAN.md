<objective>
Turn a `SequenceResult` into rows a screen can render: a BPM badge and a Camelot badge on every
track in the running order, and one collapsed bucket holding everything that did not make it,
each entry carrying the sequencer's own plain-language reason.

Purpose: SEQ-11 and SEQ-07. Both requirements are worded as things the user *sees*, which is
exactly why they are built here as value types rather than inside a view: there is no simulator
runtime on this machine, so a rule living in a `View` body is a rule that cannot be verified
tonight. `CrateRows.make(result:crate:)` is a pure function, so "every track shows a badge" and
"unresolved and excluded share one section" become `#expect`s instead of hopes.

Output: `TrackBadges`, `CrateRows`, and three thin views that project them.
</objective>

<constraints>
- **D7 — unresolved and excluded share ONE bucket, each row carrying its own `reason` string.
  Not two UI sections.** `SequenceResult.notIncluded` is already one array by design; this plan
  must not re-split it by inspecting the reason text. If you write
  `filter { $0.reason.contains("BPM") }` you have re-introduced the two sections D7 forbids.
- **Reasons are rendered verbatim.** The sequencer (plan 01-04) owns the wording; read the exact
  strings from `01-04-SUMMARY.md`. This plan does not rephrase, prefix, or localise them. A
  second copy of the wording is a second thing to drift.
- **D6 — the badge shows the FOLDED BPM.** The sequencer gated on `BPMRules.fold(bpm)`; if the
  badge showed the raw 87 while the list ordered it at 174, the screen would contradict itself.
  Fold once, in `TrackBadges`, using the shared helper — never a local `bpm < 100 ? ...` copy.
- **D8 — Core imports no SwiftUI.** `TrackBadges` and `CrateRows` hold `String`s, not `Text`s,
  not `Color`s, not `Font`s. Styling belongs to the three views.
- No simulator runtime and no signing identity exist. The views' only gate is
  `Scripts/build-app.sh` (device SDK, `CODE_SIGNING_ALLOWED=NO`). Never attempt a simulator build.
</constraints>

```swift
public struct TrackBadges: Sendable, Hashable {
    public static let placeholder = "—"     // U+2014 em dash

    public let bpm: String      // "174", "173.5", or the placeholder — never empty
    public let key: String      // "8A" or the placeholder — never empty

    public init(track: Track)
    public init(bpm rawBPM: Double?, camelot rawKey: String?)

    /// True when either badge is a placeholder — the views dim those rather than hiding them.
    public var isIncomplete: Bool { bpm == Self.placeholder || key == Self.placeholder }
}
```

BPM formatting, once, here:
```swift

let rounded = (folded * 10).rounded() / 10
bpm = rounded == rounded.rounded()
```

```swift
public struct SequencedRow: Identifiable, Sendable, Hashable {
    public let id: UUID              // the Track's id
    public let vinylID: UUID
    public let indexLabel: String    // "1", "2", ... — one-based
    public let title: String         // Track.displayName
    public let badges: TrackBadges
}

public struct NotIncludedRow: Identifiable, Sendable, Hashable {
    public let id: UUID              // the vinylID
    public let label: String         // VinylEntry.label
    public let reason: String        // D7: the sequencer's own words, verbatim
    public let badges: TrackBadges   // best-known candidate, or placeholders
}

public struct CrateRows: Sendable, Hashable {
    public let sequenced: [SequencedRow]
    public let notIncluded: [NotIncludedRow]      // D7: ONE bucket. There is no second array.

    public var showsNotIncludedSection: Bool { !notIncluded.isEmpty }
    public var notIncludedHeader: String { "Not in the set (\(notIncluded.count))" }

    public static func make(result: SequenceResult, crate: Crate) -> CrateRows
    public static let empty = CrateRows(sequenced: [], notIncluded: [])
}
```

`make` in four lines of intent:
1. `sequenced` = `result.sequence.enumerated().map { SequencedRow(...) }` — index + 1 as the label.
2. Build a `[UUID: VinylEntry]` lookup from `crate.vinyls` once, outside the loop.
3. `notIncluded` = `result.notIncluded.compactMap` over that lookup — `compactMap`, so a stale
   vinylID is skipped rather than trapped.
4. Best-known badges for a not-included row: the vinyl's candidate with the highest non-nil BPM
   (that is the one whose tempo the exclusion is *about*); if none has a BPM, take the first
   candidate so at least a key can show; if there are no candidates at all, placeholders.

**Do not** partition `notIncluded` by reason, do not sort it (the sequencer already returns it in
stable first-appearance order), and do not add an `excluded` / `unresolved` pair of properties
"for convenience". D7 is one bucket; the reason string is what distinguishes the rows, and it is
already there.

```swift
struct NotIncludedSectionView: View {

}
```
