<objective>
The Core half of the capture loop: the twelve real photographs turned into committed Swift data,
the sleeve-sized framing guide as a value type, the capture session that tracks what has been
shot and decides when to ask about a flip side, and the one `async` seam Phase 10 swaps a real
camera into.

suppression rule). Every one of them is a *rule*, and a rule tested in Core runs in
milliseconds with no simulator — which is why the screen in 03-03 gets to hold none of them.

Output: `FixtureObservations` (generated, 12 fixtures / 104 observations), `FramingGuide`,
`CaptureItem`, `CaptureItemStatus`, `CaptureSession`, `PhotoCapturing`, `FixturePhotoSource`,
`FixtureLineSegmenter`, and three test files.

The shape of one record in `.local/ocr/ocr2_out.json` (a list of 12):

```json
{ "file": "IMG_0498.HEIC", "count": 11, "ms": 455,
  "obs": [ { "text": "HIGHER", "conf": 1, "angle": -93.945, "x": 0.805, "y": 0.413,
             "w": 0.145, "h": 0.456 }, ... ] }
```

`angle` is in DEGREES in the JSON. `TextObservation.baselineAngle` is documented as RADIANS.
Convert on the way in — `angle * .pi / 180` — and assert one known value in the test so the
conversion cannot silently be skipped.
