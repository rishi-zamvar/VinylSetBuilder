**Fallbacks, decided in advance:**
- **The simulator refuses to boot:** `xcrun simctl shutdown all; xcrun simctl boot <UDID>;
  xcrun simctl bootstatus <UDID> -b`, re-run once. `xcrun simctl erase` is the last resort and it
  wipes the runner container, so re-run the full test rather than collecting from a stale one.
- **`collect-screenshots.sh` reports no container:** it copies the *current* container only, so
  running it without a preceding `ui-test.sh` silently re-copies the previous run's PNGs and they
  look like fresh evidence. Re-run `ui-test.sh` first.
- **A screenshot count is short.** Do **not** re-run `collect-screenshots.sh` on its own hoping to
  make up the difference — that is exactly how a leftover becomes evidence. Purge, re-run the
  test, re-collect, and if a state is genuinely unreachable, drop it, say so, record the real count
  in the manifest, and add a UAT row. A declared missing state beats a manufactured one.
- **A gate does not exit clean.** Report it in full with the reason, as Phase 2 did with `mktemp`'s
  `XXX`. Do not pipe it through a filter to manufacture an exit code.
- **`./Scripts/build-app.sh` fails on `Unable to find module dependency`:** known issue U7;
  `rm -rf build/` and re-run once before treating it as real.
