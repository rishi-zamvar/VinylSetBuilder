Three private helpers, and only three — every store interaction goes through one of them, so
none of them can be forgotten:

```swift
/// Rebuild from the store's truth and re-derive the whole sequence. Called on appear and after
/// any store mutation. A crate that is gone (it was deleted) closes the screen rather than
/// rendering an empty one.
private func load() {
    guard let crate = model.store.crate(crateID) else { model.store.closeToList(); return }
    var d = CrateDetailModel(crate: crate)
    d.resequence(using: sequencer)
    detail = d
}

/// Write an edited crate value back. One place, so a manual reorder cannot silently fail to
/// persist across a navigation.
private func commit(_ d: CrateDetailModel) {
    model.store.update(d.crate)
    detail = d
}

private func removeVinyl(_ vinylID: UUID) {          // CRATE-06
    model.store.removeVinyl(vinylID, from: crateID)
    load()
}
```

Body — a `List` with two sections, `.environment(\.editMode, $editMode)` on the List:

**Section 1 — the running order (CRATE-03, CRATE-04, SEQ-11).**
```swift
Section {
    ForEach(detail.rows.sequenced) { row in
        SequencedRowView(row: row)
            .accessibilityIdentifier("sequenced-row-\(row.indexLabel)")
    }
    .onMove { offsets, offset in                     // CRATE-04
        var d = detail; d.moveRows(fromOffsets: offsets, toOffset: offset); commit(d)
    }
    .onDelete { offsets in                           // CRATE-06
        // A row is a track; removing it removes the whole VINYL, because a crate holds
        // vinyls and the sequencer picks one track from each.
        for index in offsets { removeVinyl(detail.rows.sequenced[index].vinylID) }
    }
} header: {
    HStack {
        Text(detail.orderingMode == .manual ? "Custom order" : "Running order")
            .accessibilityIdentifier("ordering-mode-label")
        Spacer()
        if detail.orderingMode == .manual {
            Button("Restore") { var d = detail; d.clearManualOrder(); commit(d) }
                .accessibilityIdentifier("restore-sequenced-order-button")
        }
    }
}
```
An empty running order renders a `ContentUnavailableView`-style row rather than a blank list —
`Text("Nothing sequenced yet")` with identifier `empty-running-order`. A newly created crate
lands here and a blank screen reads as a crash.
